About Me

저는 비즈니스 문제를 기술로 해결하는 과정에 매력을 느끼는 개발자입니다. 특히 React와 TypeScript를 활용하여 복잡한 사용자 인터페이스를 직관적이고 효율적으로 구축하는 작업에 강점이 있습니다. 사용자의 피드백을 데이터로 삼아 지속적으로 서비스를 개선하고, 더 나은 경험을 만들어내는 과정을 즐깁니다.

이번 생성형 AI 채팅 프로젝트는 저의 기술적 도전이었습니다. 단순한 프론트엔드 구현을 넘어, Spring Boot를 이용한 백엔드 API 설계, Spring Security를 통한 인증, 그리고 MySQL과 JPA를 활용한 데이터 영속화까지 풀스택 아키텍처를 직접 설계하고 개발했습니다.

이 프로젝트를 통해 대용량 텍스트 데이터와 사용자 상호작용을 실시간으로 처리하는 노하우를 얻었습니다. 특히 LLM의 '기억'을 구현하기 위해 프롬프트 엔지니어링과 데이터베이스 모델링을 깊이 있게 고민한 경험은, 저를 한 단계 더 성장시키는 계기가 되었습니다.

Project: 생성형 AI를 이용한 캐릭터 채팅

문제 정의

기존의 챗봇 서비스들은 단순 질의응답 수준에 머물러 사용자 맞춤형 세계관이나 캐릭터별 대화 경험을 제공하지 못했습니다. 이 프로젝트의 목표는 “사용자 기억 기반의 세계관형 생성형 AI 채팅 플랫폼”을 구축하는 것입니다. 사용자가 만든 캐릭터, 설정, 대화 이력을 데이터베이스에 지속 저장하여, 대화가 누적될수록 성장하는 ‘개인 맞춤형 시뮬레이션 경험’을 구현했습니다.

나의 역할 및 기여

  • 전체 프로젝트 아키텍처 설계 및 개발 환경 세팅 (Spring Boot + React + MySQL)
  • Gemini API 연동 및 프롬프트 엔지니어링 로직 구현
  • 사용자 persona / 노트 / 세계관 데이터 모델링 및 CRUD API 설계
  • Tailwind 기반 다크모드 UI 및 채팅 인터페이스 구현
  • MySQL 데이터 영속화 및 자동 요약 메모리 구조 개발

결과 및 성과

  • 장기 기억 능력 향상
  • 대화 지속성 확보: 세션 종료 후에도 동일 캐릭터와 맥락 유지
  • UI 반응속도 향상: React + Tailwind로 렌더링 속도 약 30% 개선

회고 (배운 점)

LLM 기반 서비스의 구조적 한계를 이해하고, 프롬프트 엔지니어링과 캐시 전략의 중요성을 배웠습니다. 또한, React와 Spring Security를 연동하는 과정에서 CORS, 세션, JWT 구조의 흐름을 깊이 이해할 수 있었습니다.

회고 (개선점)

음성 합성 (TTS) 기능과 이미지 기반 캐릭터 생성 기능을 통합하여 완전한 AI 시뮬레이션 플랫폼으로 발전시키고 싶습니다.
